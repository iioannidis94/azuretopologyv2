#### 1. **Standalone Validation Tool** (`Validate-AzureDeployment.ps1`)

A comprehensive PowerShell validation script that checks:
- ✅ PowerShell syntax errors
- ✅ Missing required field placeholders (`<REQUIRED:...>`)
- ✅ Resource count and dependencies
- ✅ Azure PowerShell module installation
- ✅ Authentication requirements

**Usage:**
```powershell
.\Validate-AzureDeployment.ps1 -ScriptPath ".\azure-deploy.ps1" -CheckAzModule -DetailedReport
```

## How to Use the New Features

### Step 1: Design Your Architecture
Use Azure Architecture Builder to create your architecture diagram as usual.

### Step 2: Export PowerShell Script
Click "⚡ Deploy via PowerShell" button.

**You will immediately see:**
- A validation banner (green/yellow/red)
- The complete PowerShell script with validation summary
- Clear instructions on what to do next

### Step 3: Fix Any Issues (if Red Banner)
If you see a **red banner**:
1. Download the script
2. Open it in a text editor
3. Search for `<REQUIRED:` 
4. Replace all placeholders with actual values
5. Re-export or manually validate (Step 4)

### Step 4: Validate Before Deployment
```powershell
.\Validate-AzureDeployment.ps1 -ScriptPath ".\azure-deploy.ps1" -CheckAzModule -DetailedReport
```

This will:
- Check syntax
- Verify all required fields are filled
- Check Azure modules
- Provide detailed recommendations

### Step 5: Deploy to Azure
Once validation shows **"✓ DEPLOYMENT READY"**:
```powershell
Connect-AzAccount
Set-AzContext -Subscription "<your-subscription>"
.\azure-deploy.ps1
```

## Technical Details

### Validation Checks Performed:

1. **Resource Configuration Validation**
   - Checks all resources against `REQUIRED_FIELDS` definitions
   - Validates critical fields (e.g., `storageAccountName`, `sku`, `size`)
   - Warns about optional but recommended fields

2. **Script Syntax Validation**
   - Uses PowerShell parser to detect syntax errors
   - Reports line numbers for errors

3. **Placeholder Detection**
   - Scans for `<REQUIRED:...>` patterns
   - Reports unique missing fields with occurrence counts

4. **Resource Counting**
   - Counts all Azure resources to be created
   - Estimates deployment complexity

5. **Module Availability** (optional)
   - Checks if required Az modules are installed
   - Provides installation commands

6. **Naming Conflict Detection**
   - Identifies duplicate resource names
   - Prevents deployment failures
