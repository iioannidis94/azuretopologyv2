☁️ Import Azure Resource Inventory

    

      
      

        
Option A — Az CLI (Resource List):

        
az resource list --output json > azure-inventory.json

        
      

      

        
Option B — Az CLI (Resource Graph - recommended for large environments):

        
az graph query -q "Resources | project id, name, type, location, resourceGroup, properties, sku, kind, tags" --first 1000 -o json > azure-inventory.json

        
      

      

        
Option C — PowerShell Module:

        
Get-AzResource | ConvertTo-Json -Depth 10 | Out-File azure-inventory.json
